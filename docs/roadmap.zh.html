阶段 8：同步、移动端、扩展组件

  • 云文件夹兼容。
  • 高级 Git 友好工作流。Git 可以作为高级用户的可选能力，但基础本地历史不应要求安装 Git。

  • 可选的托管同步。
  • 移动端探索。
  • Web 存储适配器。
  • 主题 API。
  • 扩展 API、扩展安装目录、组件权限声明和社区扩展目录。
  • 工作区自动化钩子。
  • 更改工作区位置时迁移旧工作区文件。

已知残留问题

  • 块链接能打开目标笔记并滚动到目标块，但目标块的可视高亮在桌面编辑器里仍不稳定，当前可能看不到。后续需要单独修复跳转后的高亮定位和渲染。

暂时不做

  • 实时多人协作
  • 完整的公开论坛
  • 社交推荐信息流
  • 社区扩展目录
  • 复杂结构化数据库笔记
  • 复杂项目管理
  • 移动端优先编辑
  • 托管同步
  • 一体化网站生成
  • 跨用户 AI 搜索

这个路线的目的，是避免一开始就被平台、社区、同步、扩展目录和网站生成器这些复杂任务拖住。先让个人工具成立，再谈公开网络。
