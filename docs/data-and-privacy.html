Data and Privacy

Opaline is designed as a local-first desktop knowledge workspace.

Workspace Data

Documents/
  Opaline/
    notes/
    assets/
    .opaline/
  • notes/ stores durable HTML notes.
  • assets/ stores images and attached files.
  • .opaline/ stores app metadata, indexes, settings, cache, and history snapshots.

Network and AI

Local note editing does not require a cloud account. Network access can happen when users configure AI providers, fetch model lists, run plugins/scripts, or open external links.

AI keys are user-provided secrets. Public alpha builds should not be used with sensitive production credentials unless the user has reviewed the code and understands the risk.

Backups

Before testing alpha builds with important notes, back up the workspace folder.
