Roadmap and Non-Goals

Status Legend

  • ✓Implemented in the current alpha.

中文概要

这一页说明阶段路线和暂时不做的事情。早期重点是可信的本地 HTML 笔记、搜索、链接和 SQLite 索引。AI、发布、公开知识网络、移动端和扩展组件都应该排在后面。

这个路线的目的，是避免一开始就被平台、社区、同步、扩展目录和网站生成器这些复杂任务拖住。

  • Phase 0 应该先把文档、格式、默认工作区和基础技术栈定稳。
  • Phase 1 只追求本地笔记可信保存，并让用户无需先选择目录就能开始。
  • Phase 2 和 Phase 3 让用户能找回和连接自己的知识。
  • AI、发布、公开知识网络是后续增长方向，不能压垮 MVP。

路线图的重点是顺序感：先让个人工具成立，再谈公开网络。

Phase 3: Knowledge Links

  • Title shortcut links that save as ordinary HTML links.
  • Resolve links to stable IDs.
  • Distinguish file-level, heading-level, block-level, and concept-level relationships in the Relationship map model.
  • Expose current-note map context and edge details in the relationship-map view.
  • Update links when notes move.
  • Mentions.
  • Outgoing links.
  • Broken-link detection.
  • Journal notes.
  • Today capture that appends user and AI turns to today's local HTML journal.
  • Full relationship-map view with relation-type filters.

  • ✓Callouts.
  • ✓Code blocks.

  • ✓Embeds.
  • ✓Math.
  • ✓Diagrams.
  • ✓Block IDs.
  • ◐Block references; target highlighting still needs polish.

Phase 7: Reader Search and Public Knowledge

  • Select-to-search on published pages.
  • Search within the current author.
  • Show related public notes.
  • AI explanations with citations.
  • Public glossary or concept pages.
  • Optional Diandanr integration.

Phase 8: Sync, Mobile, Extensions

  • Cloud-folder compatibility.
  • Advanced Git-friendly workflows. Git can be optional for power users, but Opaline's basic local history should not require Git or ask users to install it.
  • Richer history retention choices: 7, 30, 90 days, forever, and maximum workspace history size.
  • Optional hosted sync.
  • Mobile exploration.
  • Web storage adapter.
  • Theme API.
  • Extension API, extension install directory, component permission declarations, and community extension directory.
  • Workspace automation hooks.
  • Restore-from-backup and old-workspace cleanup helpers for workspace migrations.

Known Residual Issues

  • Block links can open the target note and scroll to the target block, but the visible target highlight is still unreliable in the desktop editor and may not appear. A follow-up should fix highlight positioning and rendering after block navigation.

  • a community extension directory
  • advanced structured database-style notes
  • complex project management
  • mobile-first editing
  • hosted sync
  • all-in-one website generation
  • cross-user AI search
