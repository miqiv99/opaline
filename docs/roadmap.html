Roadmap and Non-Goals

中文概要

这一页说明阶段路线和暂时不做的事情。早期重点是可信的本地 HTML 笔记、搜索、链接和 SQLite 索引。AI、发布、公开知识网络、移动端和插件系统都应该排在后面。

这个路线的目的，是避免一开始就被平台、社区、同步、插件市场和网站生成器这些复杂任务拖住。

  • Phase 0 应该先把文档、格式、默认工作区和基础技术栈定稳。
  • Phase 1 只追求本地笔记可信保存，并让用户无需先选择目录就能开始。
  • Phase 2 和 Phase 3 让用户能找回和连接自己的知识。
  • AI、发布、公开知识网络是后续增长方向，不能压垮 MVP。

路线图的重点是顺序感：先让个人工具成立，再谈公开网络。

Phase 0: Foundation

  • Initialize Tauri and React.
  • Choose package manager and formatter.
  • Add Tiptap editor baseline.
  • Add SQLite integration.
  • Define the first Opaline HTML Profile.
  • Decide default workspace conventions and remember user-selected locations.
  • Add basic test and build commands.

Phase 1: Trustworthy Local Notes

  • Auto-initialize a default local workspace.
  • Allow workspace location changes from Settings.
  • Create a note.
  • Edit with Tiptap.
  • Save as clean HTML.
  • Load existing HTML notes.
  • Auto-save changes.
  • Rebuild SQLite metadata from files.
  • Show file tree and recent notes.

Phase 2: Search and Navigation

  • Title search.
  • Body search.
  • Heading extraction.
  • Tag extraction.
  • Recent notes.
  • Favorites.
  • Basic command palette.
  • Broken file detection.

Phase 3: Knowledge Links

  • [[note links]].
  • Resolve links to stable IDs.
  • Distinguish file-level, heading-level, block-level, and concept-level relationships in the graph model.
  • Expose current-note graph neighborhoods and edge details in the graph view.
  • Update links when notes move.
  • Backlinks.
  • Outgoing links.
  • Broken-link detection.
  • Daily notes.
  • Today chat that appends user and AI turns to the daily HTML note.
  • Full graph view with relation-type filters.

Phase 4: Rich HTML Blocks

  • Tables.
  • Task lists.
  • Callouts.
  • Code blocks.
  • Images and attachments.
  • Embeds.
  • Math.
  • Diagrams.
  • Block IDs.
  • Block references.
  • Ordinary-user flows to copy the current block link and insert heading or block links from the editor.
  • Settings expose built-in widgets, installed plugin widgets from .opaline/plugins, and experimental script notes; users can import plugin folders instead of editing scripts inside Settings.
  • Concept spans and ordinary-user context-menu flows for creating concept relationships.

Phase 5: AI-Assisted Knowledge Work

  • Configure AI providers, custom API base URLs, models, keys, model tests, and model fetching from Settings.
  • Continue the Today conversation after recording the user's raw text locally.
  • Summarize a note.
  • Generate titles.
  • Extract tags.
  • Suggest related notes.
  • Detect duplicate or overlapping notes.
  • Turn rough writing into outlines.
  • Refactor long notes into smaller linked notes.
  • Ask questions over the workspace with citations.
  • Convert imported Markdown or web pages into clean Opaline HTML.

Phase 6: Publish

  • Select notes for publishing.
  • Generate static HTML site.
  • Include assets.
  • Include search index.
  • Include backlinks and table of contents.
  • Support custom theme basics.
  • Preserve public and private boundaries.

Phase 7: Reader Search and Public Knowledge

  • Select-to-search on published pages.
  • Search within the current author.
  • Show related public notes.
  • AI explanations with citations.
  • Public glossary or concept pages.
  • Optional Diandanr integration.

Phase 8: Sync, Mobile, Plugins

  • Cloud-folder compatibility.
  • Git-friendly workflows.
  • Optional hosted sync.
  • Mobile exploration.
  • Web storage adapter.
  • Theme API.
  • Plugin API, plugin install directory, component permission declarations, and plugin marketplace.
  • Workspace automation hooks.
  • Migrate old workspace files when users change workspace location.

Known Residual Issues

  • Block links can open the target note and scroll to the target block, but the visible target highlight is still unreliable in the desktop editor and may not appear. A follow-up should fix highlight positioning and rendering after block navigation.

Not Doing First

  • real-time multiplayer collaboration
  • a full public forum
  • a social recommendation feed
  • a plugin marketplace
  • Notion-style databases
  • complex project management
  • mobile-first editing
  • hosted sync
  • all-in-one website generation
  • cross-user AI search
