# Sponsorship

Opaline is a source-available, noncommercial project. Sponsorship helps fund continued work on the local-first HTML note editor, storage model, search, links, publishing, and AI-assisted knowledge workflows.

## GitHub Sponsors

After GitHub Sponsors is configured, add the sponsor handle to `.github/FUNDING.yml`:

```yml
github: [your-github-sponsors-handle]
```

## PayPal

GitHub Markdown cannot embed PayPal's full hosted button form because scripts and forms are restricted. Use a normal PayPal link or a badge-style Markdown link instead.

Example README badge:

```md
[![Sponsor via PayPal](https://img.shields.io/badge/Sponsor-PayPal-00457C?logo=paypal&logoColor=white)](https://www.paypal.me/your-paypal-handle)
```

Example `.github/FUNDING.yml` custom link:

```yml
custom:
  - https://www.paypal.me/your-paypal-handle
```

Replace placeholders only after the payment profile is ready.
