愿景和定位

产品定位

Opaline 是一个以干净 HTML 为原生笔记格式的本地优先知识工作台。

它从一个个人桌面笔记应用起步，但更大的愿景是：笔记应该是持久的本地文档，可以被舒适地编辑、深度搜索、相互链接、发布为网页，并最终由 AI 带引用地查询。

核心理念

Obsidian 证明了本地 Markdown 文件可以成为严肃的个人知识库。Opaline 探索的是一个相关但不同的赌注：

富知识笔记应该以干净的本地 HTML 保存，因此每篇笔记从一开始就是可阅读的文档、可发布的网页、也是 AI 辅助整理的结构化知识源。

第一用户

第一用户是作者，而不是公开读者。Opaline 应该服务于随着时间积累知识的人：研究者、写作者、开发者、学生、产品思考者和技术创作者。

第一产品闭环

写下来 -> 存得住 -> 找得到 -> 连得上 -> 以后能发布

长期方向可以向公开知识网站和面向读者的 AI 搜索发展，但前提是本地知识系统足够可靠。

产品原则

  • 默认本地优先。
  • HTML 文件是真实数据源。
  • SQLite 索引可重建。
  • 笔记应该在没有安装 Opaline 的情况下仍然可用。
  • 编辑器应该感觉快速、安静、严肃。
  • 搜索应该帮助用户找回旧上下文，而不仅仅是匹配关键词。
  • AI 应该提议、解释和引用。它不应该悄悄地重写知识。
  • 发布应该是文件格式的自然结果，而不是第一个产品。
  • 公开和社区功能应该在个人工具稳定之后再考虑。

与 Diandanr 的关系

Opaline 和 Diandanr 最终可以互补，但暂时应该保持独立。

Opaline  = 本地知识创建和管理
Diandanr = 发布、网站生成、分发和平台功能

阶段性目标

  • 短期：让个人能放心把真实笔记交给 Opaline。
  • 中期：让笔记能被搜索、链接、整理和 AI 检索。
  • 长期：让公开笔记成为可阅读、可引用、可追问的知识网络。

Opaline 的第一性问题不是"能做多少功能"，而是"能不能长期保存和理解用户自己的知识"。
