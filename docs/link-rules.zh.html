链接规则

[[note]] 笔记链接

保存时，Opaline 会把 [[标题]] 编译成普通 HTML 链接。如果能按标题找到目标笔记，保存为：

<a href="target.html" data-opaline-link="note-id" data-opaline-link-kind="note">标题</a>

如果找不到目标笔记，保存为 unresolved span，并在索引中标记为断链：

<span data-opaline-unresolved="标题">[[标题]]</span>

四类关系

当前数据模型和关系图已经区分四种关系。编辑器已经提供复制当前块链接、从当前笔记选择标题或块并插入链接的普通用户入口；从选中文字创建“概念级关系”的交互仍是后续步骤。

  • 文件级：链接到某篇笔记。
  • 标题级：链接到某篇笔记的某个标题。
  • 块级：链接到某个段落、卡片、表格、引用块等稳定块。
  • 概念级：链接到一个概念节点，当前标签会先进入关系图成为概念节点。
<a href="target.html" data-opaline-link="note-id" data-opaline-link-kind="note">目标笔记</a>
<a href="target.html#研究问题" data-opaline-link="note-id" data-opaline-link-kind="heading">研究问题</a>
<a href="target.html#b-intro" data-opaline-link="note-id" data-opaline-link-kind="block" data-opaline-block-id="b-intro">某段内容</a>
<a href="opaline://concept/RAG" data-opaline-link-kind="concept" data-opaline-concept="RAG">RAG</a>

关系图会把这些关系渲染为不同类型的边：文件、标题、块、概念。这样后续可以按关系类型过滤，而不是把所有链接都当作同一种边。

完整关系图现在可以聚焦当前笔记关联范围，也可以点击边查看关系类型、来源、目标，以及具体标题、块或概念元数据。

普通 <a> 链接

  • http:、https:、mailto:、tel: 视为外部链接，不算断链。
  • #block-id 视为当前笔记内部锚点，不算断链。
  • 相对路径如果能解析到 workspace 的 notes/ 目录内 HTML 笔记，则记录目标 note id。
  • 相对路径找不到目标笔记时，标记为断链。
  • 如果链接文本等于某篇笔记标题，也可以作为兜底解析目标。

Block Ref

块引用通过 URL hash 和 data-opaline-block-ref 表达：

<a href="target.html#b-intro" data-opaline-link="note-id" data-opaline-link-kind="block" data-opaline-block-ref="b-intro" data-opaline-block-id="b-intro">target#b-intro</a>

编辑器会在 Tiptap 状态中保留 data-opaline-block-id，创建块链接前也会补齐缺失 ID。当前索引先解析目标笔记是否存在；跨笔记精确校验 block id 是否存在，仍留给后续索引层实现。

活组件与插件

活组件使用受控、可读 HTML 表达。设置页把内置组件、已安装插件组件和实验性脚本笔记分开。

<opaline-widget type="local-graph" title="当前笔记关联范围">Opaline widget: 当前笔记关联范围</opaline-widget>
<opaline-widget type="network-status" target="192.168.1.1" endpoint="/status" profile="onu-readonly">Opaline widget: 网络设备状态</opaline-widget>
<opaline-script title="实验脚本" language="javascript">const status = await opaline.net.fetch("http://192.168.1.1/status");</opaline-script>

Opaline 可以渲染 query、chart、local-graph 等内置类型。插件组件由 .opaline/plugins 里的脚本接管，manifest.json 把组件类型映射到脚本文件，笔记只保存参数。<opaline-script> 仍是单篇笔记里的实验性脚本入口。

Broken Link

以下情况会被标记为断链：

  • [[标题]] 找不到对应笔记。
  • 相对 HTML 链接找不到目标笔记。
  • data-opaline-link 指向的 note id 不存在。
