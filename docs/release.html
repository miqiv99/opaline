Build and Release Notes

Opaline is in public alpha. Release builds are currently intended for testing and early feedback.

Commands

npm install
npm run tauri:dev
npm run tauri:build

Tauri bundle outputs are written under src-tauri/target/release/bundle/.

Platform Notes

  • Windows packages should be built on Windows. Unsigned builds may trigger SmartScreen warnings.
  • macOS packages should be built and tested on macOS. Public distribution usually needs signing and notarization.
  • Linux support is future-facing until packages are explicitly tested and documented.

Release Configuration Gaps

  • Review the Tauri app identifier.
  • Configure bundle icons.
  • Document whether each release is signed or unsigned.
  • Add release notes, checksums, and migration notes.
